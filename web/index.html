Mes portefeuilles

Vous pouvez aussi utiliser MakutaWallet, notre extension : installer l’extension et découvrir le guide. Les portefeuilles du site restent disponibles.

Vos portefeuilles sont enregistrés chiffrés dans ce navigateur. Votre mot de passe permet de signer un transfert ; il ne quitte jamais votre appareil.

Créer un portefeuille

Au moins 12 caractères. Ce mot de passe protège votre portefeuille ; nous ne pouvons pas le récupérer.

Ouvrir ou restaurer

Déverrouillez le portefeuille actif pour envoyer des MTC. Recevoir et miner ne nécessitent pas de déverrouillage.

Téléchargez une sauvegarde chiffrée pour chaque portefeuille. Si vous effacez les données du navigateur, vous aurez besoin du fichier et de son mot de passe pour retrouver vos MTC.

Envoyer des MTC

Votre portefeuille actif signe le transfert sur cet appareil. Le réseau le confirmera lorsqu’un nouveau bloc sera miné.

Disponible : —

Le destinataire trouve son adresse dans le menu « Recevoir des MTC ».

Confirmer votre transfert

Vérifiez le destinataire. Un transfert confirmé ne peut pas être annulé.

Comment se passe un transfert ?

  1. Déverrouiller

    Dans « Portefeuilles », entrez le mot de passe du portefeuille actif.

  2. Vérifier et envoyer

    Le montant est réservé dès que le réseau accepte votre transaction.

  3. Confirmer dans un bloc

    Dans « Minage », minez un bloc. Le destinataire reçoit alors les MTC.

Pourquoi miner ?

Un bloc relie les nouvelles transactions à l’histoire de notre blockchain. Le serveur cherche une preuve de travail et vérifie toutes les règles avant de confirmer.

Pour une démonstration : créez Alice et Bob, minez pour Alice, envoyez 4 MTC à Bob, puis minez pour Bob.
