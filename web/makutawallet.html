EXTENSION LOCALE · VERSION 0.1.2

MakutaWallet

Gardez vos clés dans une extension séparée du site et confirmez chaque transfert dans sa propre fenêtre.

Installer dans Chrome ou Chromium 137+

  1. Ouvrir la gestion des extensions.

    Saisissez chrome://extensions dans la barre d’adresse du navigateur.

  2. Activer « Mode développeur ».

    Cliquez ensuite sur « Charger l’extension non empaquetée ».

  3. Choisir le dossier MakutaWallet.

    Dans le projet, sélectionnez extension/makutawallet. Vous pouvez aussi télécharger le ZIP, l’extraire et choisir le dossier makutawallet obtenu.

  4. Épingler et ouvrir MakutaWallet.

    Dans le bouton Extensions du navigateur, épinglez MakutaWallet. Créez un portefeuille et sauvegardez-le, ou restaurez une sauvegarde chiffrée téléchargée depuis notre site.

Déjà installée ? Ouvrez chrome://extensions et cliquez sur « Recharger » sur la fiche MakutaWallet. Le clic sur son icône ouvre désormais une fenêtre durable qui reste visible.

Utiliser votre portefeuille

  1. Actualisez Makutachain après l’installation, puis cliquez sur Connecter MakutaWallet dans l’en-tête.
  2. Vérifiez l’adresse du site dans la fenêtre de l’extension et autorisez la connexion.
  3. Le portefeuille apparaît dans le sélecteur du site. Vous pouvez recevoir des MTC, copier son adresse ou miner vers cette adresse.
  4. Préparez un transfert dans Envoyer. Vérifiez le récapitulatif du site puis confirmez le destinataire et le montant dans MakutaWallet avec votre mot de passe.
  5. Minez un bloc pour confirmer le transfert. Consultez l’explorateur pour vérifier son état.

L’extension fonctionne uniquement avec localhost ou 127.0.0.1 sur les ports 5000 et 5001. Elle n’est pas publiée sur le Chrome Web Store. Le portefeuille du site reste utilisable.

Comparer les soldes

Le site et MakutaWallet actualisent automatiquement les soldes environ toutes les cinq secondes. Vérifiez la même adresse et le même serveur. Le disponible tient compte des transferts réservés. Après un changement de compte dans l’extension, reconnectez le site.

Ce qui reste protégé

Le site reçoit l’adresse et les transactions signées. Il ne reçoit ni le mot de passe, ni la clé privée, ni le coffre chiffré de l’extension. La connexion seule n’autorise aucune signature.

Le coffre est verrouillé entre les signatures. Les demandes expirent après deux minutes. Changer de portefeuille dans l’extension révoque les autorisations des sites ; reconnectez ensuite le site.

Version pédagogique, sans audit indépendant. La fenêtre de signature doit provenir de l’extension du navigateur. Ne saisissez jamais son mot de passe dans une page qui prétend être MakutaWallet. Un navigateur ou une extension compromis restent un risque.
