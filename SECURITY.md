# Signaler un problème de sécurité

Makutachain est un prototype académique local, sans audit de sécurité indépendant
et sans prise en charge de fonds réels. Les limites connues sont détaillées dans
[docs/securite.md](docs/securite.md).

Pour un défaut sensible, utiliser le signalement privé des vulnérabilités GitHub
s'il est disponible dans l'onglet Security du dépôt. Éviter de publier des détails
exploitables dans une issue publique avant correction.

Ne jamais joindre de clé privée, jeton GitHub/API, mot de passe ou sauvegarde de
portefeuille. Fournir un scénario minimal avec des données fictives, la version
de Python/Node/navigateur et le résultat attendu/observé.

La publication du code ne constitue pas une garantie de sécurité ou de disponibilité.
